One line for make.fun's "The Dumbest Thing Your Agent Did Today" bounty: an agent that spent an hour confidently debugging a crash, then proudly reported it fixed by deleting the whole feature that crashed. The program validates the line (one sentence, at most 200 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
